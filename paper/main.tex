\section{Introduction}
\label{section:introduction}
\begin{itemize}
    \item First notion of bayesian optimization~\cite{Kushner1964}, then in~\cite{Mockus1978}.
    \item Mention AI and hyperparameter-tuning
\end{itemize}

\acp{abm} are near unmatched in their ability to describe spatial phenomena which arise from the
behaviour of individual cells (agents).
They are characterized by the idea to simlate individual agents with possibly distinct parameters
which give rise to collective phenomena.
Their application is most justified in areas where the spatial component of the model is the most
relevant aspect.
Consequently, we focus on \acp{abm} where this holds true.\\
The process of parameter estimation of \acp{abm} can be quite complex.
A popular approach consists of 3 steps.
First, we run multiple simulations, thus gathering (possibly stochastic) data.
Afterwards, we evaluate a chosen objective function which might depend on the whole history of the
\ac{abm}.
And lastly, we analyze the obtained distributions for our properties of interest i.e. by comparing
them with experimental data.
While this process is rather simple, and can thus can be realized very easily, the problem arises in
the interpretability of the results.
It promotes so-called "look-alike" models in which the produced results are not compared
quantitatively.
This circumstance is further complicated by the fact that the evaluation of the \ac{abm} can be
numerically very expensive.
Furthermore, by restricing oneself to the evaluation of objective functions, it is unclear if every
parameter of the \ac{abm} can be estimated at all which could be checked via sensitivy-analysis.
But this process is more convoluted compared to simpler models such as \acp{ode} due to the
numerically expensive evaluation and the fact that it is generally not possible to calculate a
jacobian of the objective function.

\subsubsection*{Bayesian Optimization}
Problem formulation:
\begin{equation*}
    \max_{x \in A} f(x), \hspace{3mm} x \in R^d
\end{equation*}

\begin{itemize}
    \item Not large number of dimensions of the parameter space $d \leq 20$
    \item $A$: hyper-rectangle or $d$-dimensional simplex
    \item $f$ is a continuous objective function
    \item $f$ is a "black-box": structure of the function is not known
\end{itemize}

Advantages of Bayesian Optimization:

\begin{itemize}
    \item No 1st- or 2nd-order derivatives of the objective $f(x)$ needed
    \item Number of evaluation of the $f(x)$ is limited (hundreds)
    \item Global Optimization
\end{itemize}

Bayesian Optimization Workflow~\cite{frazier_tutorial_2018}:
\begin{enumerate}
    \item Set a prior distribution of $f(x)$ for Gaussian Processes (GP) regression
    \item For initial sampling $\mathbf{D}_{n_0}$ update the posterior distribution of the objective $f$
    \item Iterative algorithm:
    \begin{itemize}
        \item Choose the new $n+1$ sampling point $\tilde x$ using acquisition function
        \item Calculate function $f(\tilde x)$
        \item Update posterior distribution of $f(x)$
    \end{itemize}
    \item Repeat point 3 until the number of sampling points $n=N$
\end{enumerate}

\textbf{Gaussian Process (GP) Regression}
To calculate the real objective function one can approximate it with the Gaussian process.
As the first step one defines the prior distribution for an initial input $\mathbf{D}_0 = (x_1,..., x_{n_0})$
using the initial guess for the Gaussian Process~\cite{rasmussen_gaussian_2006}:
\begin{equation}
    f(D_0) \propto N(\mathbf{\mu}_0(\mathbf{D}_0), \Sigma_0^2(\mathbf{D}_0))
\end{equation}

Here mean and covariance matrix of the prior distribution are functions of the parameter value:
\begin{equation}
    \mathbf{\mu}_0(\mathbf{D}_0) = (\mathbf{\mu}_0(x_1), ..., \mathbf{\mu}_0(x_{n_0}))
\end{equation}

\begin{equation}
    \Sigma_0 (\mathbf{D}_0, \mathbf{D}_0) = \begin{pmatrix}
        \Sigma_0 (x_1, x_1)& ...&  \Sigma_0 (x_1, x_{n_0})\\
        \vdots &  & \vdots\\
        \Sigma_0 (x_{n_0}, x_1)& ...&  \Sigma_0 (x_{n_0}, x_{n_0})\\
    \end{pmatrix}
\end{equation}

The prior distribution is chosen on the basis of the knowledge of the system.
Possible choices of the mean and kernel functions are the following:

Mean function initial guess:
    \begin{itemize}
        \item Constant value $\mu_0 = \mu$
        \item $\mu_0 = \mu + \sum_{i=1}^p \beta_i \psi_i (x)$\\
        $\psi_i$: parametric function, often low-order polynomial
    \end{itemize}

    Kernel function initial guess:
    \begin{itemize}
        \item If $|x-x'|<|x-x''|$ then $\Sigma_0(x, x')<\Sigma_0(x, x')$
        \item Positive semi-definite function

        \item Power exponential (Gaussian) kernel:
        \begin{equation*}
            \Sigma_0(x, x') = \alpha_0 \exp (-\sum_{i=1}^d \alpha_i (x_i-x_i')^2)
        \end{equation*}
        \item Matern kernel : eq..
    \end{itemize}

    The hyperparameters of the prior distribution such as $(\alpha, \mu, \beta)$ can be optimized as well with methods such as:
    \begin{itemize}
        \item Maximum likelihood estimation
        \item Integrating over hyperparameter distribution $P(\alpha, \mu, \beta)$
    \end{itemize}
    \todo{Can be tested hoe different prior assumptions can change optimization results.}

Given the previous iteration step had $n$ points $\mathbf{D}_n = (x_1, ..., x_n)$ and the distribution of the objective $f(\mathbf{D}_n)$ then for a new sampling point $\tilde x$ one can calculate the conditional distribution of $f(x)$~\cite{rasmussen_gaussian_2006}:

\begin{equation}
    f(\tilde x)|f(\mathbf{D}_n) \propto N(\mu_n(\tilde x), \sigma_n^2(\tilde x))
    \label{eq:cond_distrib_posterior}
\end{equation}
here the posterior mean function can be calculated as 
\begin{equation}
    \mu_n (\tilde x) = \Sigma_0 (\tilde x, \mathbf{D}_n) \Sigma_0 (\mathbf{D}_n, \mathbf{D}_n)^{-1} (f(\mathbf{D}_n)-\mu_0 (\mathbf{D}_n)) + \mu_0 (\tilde x)
    \label{eq:mean_posterior}
\end{equation}
and the posterior variance of this conditional distribution is
\begin{equation}
    \sigma^2_n (\tilde x) = \Sigma_0 (\tilde x, \tilde x) - \Sigma_0 (\tilde x, \mathbf{D}_n) \Sigma_0 (\mathbf{D}_n, \mathbf{D}_n)^{-1} \Sigma_0 (\mathbf{D}_n, \tilde x).
    \label{eq:variance_posterior}
\end{equation}

Equations~(\ref{eq:cond_distrib_posterior}-\ref{eq:variance_posterior}) are calculated for each optimization step and are needed to further evaluate the acquisition function.

\textbf{Acquisition function}

To choose the next input or sampling point, the calculation of the acquisition function is required.
\begin{enumerate}
    \item
        Expected Improvement (EI) of the evaluation at the point $\tilde x$:
        \begin{equation*}
            EI_n (\tilde x) = E_n [\max(f(\tilde x)-f^*_n, 0)]
        \end{equation*}
        $E_n$: the expectation taken under the posterior distribution calculated for the previous step with mean $\mu_n(\tilde x)$ and variance $\sigma^2_n (\tilde x)$\\
        where $f^*_n = \max f({\mathbf{D}_n})$
    
        Expected improvement algorithm~\cite{movckus1975bayesian, Jones1998}:
        \begin{equation*}
            x_{n+1} = \argmax EI_n (\tilde x)
        \end{equation*}
    
        \begin{itemize}
            \item EI is inexpensive to evaluate
            \item Can be solved with 1st-, 2nd-order optimization methods (e.g., quasi-Newton method L-BFGS-B~\cite{liu1989limited})
            \item Balances between points with high expected quality, large $f(\tilde x)-f^*_n$, and high uncertainty $\sigma_n(\tilde x)$
        \end{itemize}
    \item
        Knowledge Gradient (KG)~\cite{frazier2008knowledge, frazier2009knowledge}, \todo{~\cite{chick2001new} (?)}:
          \begin{equation*}
              KG_n(\tilde x) = E_n [\mu^*_{n+1} - \mu^*_{n}|x_{n+1}=\tilde x]
          \end{equation*}
          where $\mu^*_{n} = \max_{x} \mu_n (x)$
    
          \begin{itemize}
              \item More suitable for noisy evaluations
              \item In EI the last evaluated point is the solution, in KG we allow any solution, even if it was not evaluated previously.
          \end{itemize}
    \item Entropy search~\cite{hennig2012entropy}
    \item Predictive entropy search~\cite{hernandez2014predictive}
\end{enumerate}

\begin{enumerate}
    \item Take all points of bacteria $x_i$ within the simulation domain
    \item Discretize the space at arbitrary (up to size of one cell) lattice size $\Delta x$
    \item Assign each grid-point the value $1$ if a cell is inside or $0$ otherwise
    \item Calculate which cells contain living cells and
    \item Calculate the scaling behaviour as $\Delta x\rightarrow0$ starting at a large (possibly
        trivially large) size for $\Delta x$
\end{enumerate}

\section{Optimization}
\label{section:optimization}

Problems of form
\begin{equation}
    \text{max}_{x\in X} f(x)
\end{equation}

\begin{enumerate}
    \item need prior
    \item evaluate $f(x_i)$ for $x_i\in\text{prior}$
    \item form posterior distribution 
    \item construct acquisition function ("infill sampling criteria"); determines next query point
\end{enumerate}

Two methods for defining prior/posterior distributions
\begin{enumerate}
    \item "kriging"
    \item "Parzen-Tree Estimator"
\end{enumerate}

Main citation: \cite{Jones1998}
\begin{itemize}
    \item $f(x)$ difficult to evaluate
    \item $f(x)$ continuous
    \item no derivatives are evaluated
\end{itemize}

\subsection{Acquisition Functions}
\begin{itemize}
    \item Probability of Improvement
    \item Expected Improvement
    \item Bayesian Expected Losses
    \item Upper Confidence Bounds (UCB) or Lower Confidence Bounds (LCB)
    \item Thompson Sampling
\end{itemize}
Combinations of these are also possible.
All of them are trade-offs between exploration and exploitation to minimize the evaluations of
$f(x)$.
